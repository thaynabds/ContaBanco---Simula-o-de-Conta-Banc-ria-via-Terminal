## 📌 Sobre o Desafio

O desafio consiste em simular a criação de uma conta bancária através do terminal/console do sistema. O programa solicita dados ao usuário através da classe `Scanner` e, após a inserção, exibe uma mensagem de boas-vindas com os dados consolidados.

Este projeto faz parte do módulo de **Sintaxe Básica Java** da **Trilha Java Básico** promovida pela **Digital Innovation One (DIO)**.

### 📋 Requisitos da Aplicação

1. Solicitar ao usuário via terminal:
   - **Número da Agência** (`String`)
   - **Número da Conta** (`int`)
   - **Nome do Cliente** (`String`)
   - **Saldo Inicial** (`double`)
2. Exibir a mensagem formatada:
   > *"Olá [Nome Cliente], obrigado por criar uma conta em nosso banco, sua agência é [Agencia], conta [Numero] e seu saldo [Saldo] já está disponível para saque."*
